# Fume Extractor

## INTRO
This is a simple fume extractor with a tiny 80x80x25 computer fan. The stand is going to be 3d printed. CAD files are available!

## WHY?
I wanted an afordable solution to keep the fumes away from me while soldering. So I just designed this!!

## HOW?
You can simply just get a copy of the STEP files from [/CAD](https://github.com/sudo-apt-install-tap/Fume-Extractor/tree/main/CAD) and just print one for yourself. The design is mainly split into two parts, a holder and a grill to accelerate the airflow.

## Note:
This in no way is a proper fume extractor. I would likly classify this as a ***fume rerouter***. This just re-routes the fumes away from the user.
